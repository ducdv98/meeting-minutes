# App screenshots

Generated by `pnpm screenshots` (`scripts/screenshots/capture.mjs`). It runs the real app UI in headless Chromium against a fake backend serving a fictional demo Library (`scripts/screenshots/demo-data.ts`) and saves a 1200 × 800 window at 2× in light and dark. The website switches between them with `prefers-color-scheme`. Re-run it after UI changes.

Demo content is fictional: never real people, calls or device details, and only in formats the app actually produces (Transcript, Summary with Citations, Answers with Citations).

- `meeting-*.png`: an open Meeting after Processing, with the Transcript, Participants and a Summary with Citations.
- `ask-*.png`: the Ask tab with two Answers and their Citations.
- `transcript-*.png`: the Transcript scrolled to the middle of the Meeting, with Participant names and timestamps.
- `search-*.png`: Library search for “pricing” with matches across several Meetings.
- `diagnostics-*.png`: the Help view with Copy diagnostics and a fictional diagnostics preview.
- `library-*.png`: the Library home table. It isn't on the website; it's for launch galleries.
- `firstrun-model-*.png`: the first-run model recommendation, opened from Help's setup guide on a PC with a GPU.

`pnpm screenshots --gallery` captures the same views at 1270 × 760 for the Product Hunt gallery into `.scratch/v1-launch/gallery/`, outside the website assets.

The non-draft build fails until every website screenshot exists, once a Release is published.
