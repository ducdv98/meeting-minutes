Windows says it protected your PC

Meeting Minutes is free and its source is public. The installer is unsigned because we do not use a paid code-signing certificate. Windows SmartScreen may warn you. Download it only from this site or the GitHub Releases page. After checking the file and deciding you trust it, choose More info and Run anyway if Windows offers those options.

Verify the installer

  1. Download the installer and its matching .sha256 file from the same GitHub Release.
  2. In PowerShell, run this command, replacing installer.exe with the downloaded file name. Compare the hash with the first value in the .sha256 file. 
    Get-FileHash ".\installer.exe" -Algorithm SHA256
  3. With the GitHub CLI, run this command using the same file name. This checks that GitHub's release workflow produced that installer. 
    gh attestation verify ".\installer.exe" --repo ducdv98/meeting-minutes

You can also build it yourself from the public source.

Uninstalling

Use Settings → Apps in Windows. Your Library in Documents\Meeting Minutes is kept. The uninstaller offers an unticked option to remove downloaded models, settings and the search index.

Windows 11 x64 is supported. Windows 10 may work, but is untested.
